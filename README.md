# 모모의 도시 시간여행

세종·인천 송도·순천의 변화를 그림과 이야기로 탐험하는 초등 사회 학습 게임입니다.

- 도시별 5장면: 흔적 찾기, 시간 복원, 주민 조사, 변화 연결, 기록 완성
- 모든 이미지와 코드를 index.html에 포함
- 평가·교사 기록실·결과 수집·제출 기능 없음
- 여행 진행은 같은 기기의 브라우저에만 저장
- 실제 변화 자료를 참고한 학습용 그림과 가상 주민 대화 사용

## GitHub Pages

Settings → Pages → Build and deployment에서 Source를 **Deploy from a branch**로 선택하고, **main / (root)**를 저장합니다.

배포가 완료되면 https://frommars-teacher.github.io/city-time-trip/ 에서 접속합니다.
